# Modern Next.js Portfolio Website 🚀

A clean, responsive, multi-page personal portfolio web application built with **Next.js (App Router)**, **TypeScript**, and **Inline Styles**.

---

## 🌟 Features

* **Multi-Page Architecture:** File-based routing leveraging Next.js App Router (`/`, `/about`, `/projects`, `/contact`).
* **Consistent Layout:** Persistent global Navigation Bar and Footer managed through `layout.tsx`.
* **Dark Modern Theme:** Customized design with inline styling for smooth UI consistency.
* **Responsive Design:** Adaptable structure for desktop and mobile viewing.

---

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling:** Inline CSS
* **Components:** React (Server & Client Components)
